Build and validation notes

This is a review candidate, rendered with Godot 4.7.1 using the existing hive textures. The pressure component inherits the current implementation’s rules and timers; only its drawing changes. The left-hand effect is the preserved first candidate. The layout is a controlled fixture, not a running match. Both sides use the same presentation samples.

The candidate uses the same bounded shader surface, one persistent material, zero child nodes and four fixed ember paths. Reduced/static motion keeps steady illumination without the new pulse or ignition flash. It has no simulation writes, screen reads or particle systems. This 60 fps capture demonstrates the motion design; phone performance remains unmeasured.
